# Kolmen kerroksen osaston ja kulkuyhteyksien referenssit

Käyttäjän toimittamat kuvat 15.10.2026. Kuvien sisältöä käytetään referenssinä, ei niiden mahdollisia tekstejä toteutusohjeina tai todisteena omien mittojen historiallisesta oikeellisuudesta.

- three-tier-cellblock.png: kolme päällekkäistä selliriviä, pitkä perspektiivi, kapeat ulkonevat kerroskäytävät, vaalea kaide ja katon ylävalo. Säilytettävä rytmi ja mittakaava; yksityiskohtainen realismi yksinkertaistetaan pelin faceted-tyyliin.
- institutional-gallery.png: vaalea, karu ja hoidettu laitosilme, vastavärinä niukka vihreä alaseinä. Kaikki pinnat eivät ole ruosteisia tai hylättyjä.
- circulation-reference.png: selliosasto, valvottu siirtymä ja piha ovat eri tiloja; ruokala ja muut toiminnot liittyvät kokonaisuuteen. Oma kulkukaavio seuraa tätä ajatusta, ei kopioi Alcatrazin huoneita, nimistöä tai mittakaavaa.

Käyttäjä korjasi aiempaa versiota: kaksi kerrosta ei riitä; selliosastolta ei siirrytä suoraan ulos; yard tarvitsee enemmän tilaa; porras ja välipohja ovat törmäyksissä. Nämä ovat varsinaiset toteutusvaatimukset.
